# 补充材料 B —— 系统与数据

## B.1 数据审计

本节详述主文 §3.2 中 263 帧原始数据的审计链，说明如何从中筛选出 248 帧 clean set 作为 SR 的默认输入。

### B.1.1 审计总览

原始数据集包含 263 对 TXT 温度矩阵与 BMP 伪彩图，每帧为 $480 \times 640$ 像素。按文件修改时间（mtime）生成的采集顺序（acquisition\_order）可将其划分为三个物理温度段：session 0 仅 1 帧（均温 21.757 °C），session 1 共 7 帧（均温 19.862 °C），session 2 共 255 帧（均温 23.292 °C）。段间温度跳变分别为 −1.662 °C（22.9 倍噪声底）和 +4.157 °C（57.4 倍噪声底），远超探测器噪声 $\sigma_n = 0.0724\;°\mathrm{C}$，因此跨 session 帧绝不可混用。

在主 session（session=2）的 255 帧中，进一步剔除重复采集标记 $R \neq 0$ 的 7 帧后，得到 248 帧 clean set，覆盖 $16 \times 16$ raster 网格中的 248/256 个坐标位置，均温跨度 0.544 °C。筛选条件为

$$\text{is\_sr\_usable} = (\text{session} = 2) \;\wedge\; (R = 0) \;\wedge\; (480 \times 640 \text{ 且无 NaN/Inf})$$

被剔除的重复帧保留为诊断用途（重复测量差异 1–2 °C std，不跨 repeat 混合）。缺失坐标为 (14,6)、(16,6)、(16,16)。

### B.1.2 文件命名解码

原始文件名为 X+Y+R 连写数字，其中 $X, Y \in \{0, 2, \ldots, 20, 24, 28, 32, 36, 40\}$，$R \in \{0, 1, 2\}$。解码时按前导零约束枚举所有合法 $(X, Y, R)$ 分割。典型歧义特判包括：`2400` 解码为 $(24, 0, 0)$ 而非 $(2, 40, 0)$；`0200` 为 $(0, 20, 0)$；`2，400`（中文逗号标注）为 $(2, 40, 0)$。

值得强调的是，文件名是坐标标识而非采集时序。按文件名字母序检测 session 会因重复帧与 raster 网格的交错而制造 13 个假温度段。正确的做法是始终使用基于 mtime 的 acquisition\_order，由此才能识别出 3 个真实温度段。

### B.1.3 AVI 与 BMP 的排除

除 TXT 温度矩阵外，数据集还包含 263 张 BMP 伪彩渲染图（仅作视觉参考）和 16 个 AVI 视频（8 X-scan + 8 Y-scan，覆盖仅 0–14 µm 精细段）。AVI 为 8-bit 渲染视频，无温度矩阵，且约 67% 为重复帧。AVI 仅用于位移方向的独立一致性检验（见 A.5.1），不作 SR 的数值输入。

## B.2 对齐管线与质量门控

### B.2.1 两级对齐

对齐管线分两级执行。第一级为 highpass NCC 初始化：先对每帧做 highpass 滤波（$\text{frame} - G_{\sigma=6}(\text{frame})$），以 6\_16\_0.txt 为参考帧，在中心 $360 \times 360$ ROI 内执行 $\pm 18$ px 整数搜索，亚像素精度通过相关峰 $3 \times 3$ 邻域的二次抛物线拟合获得。

第二级为 contour refinement：在 highpass 域提取 Sobel 梯度幅值 ≥ 93rd percentile 的边缘点（每帧最多 8000 个，确定性子采样），以最小化移动帧边缘点到参考帧边缘距离变换（EDT）的均值为目标（Chamfer 距离），在 NCC 初值 $\pm 1.0$ px 范围内以 0.25 px 步长搜索。验证时将边缘点按奇偶分为 fit 集和 holdout 集，报告的是 held-out Chamfer。

对齐链逐级 held-out Chamfer 中位/P90 如下：无对齐 0.398/0.708 px → stage command prior 0.246/0.442 px → filename affine 0.170/0.204 px → NCC 初始化 0.156/0.175 px → contour refined **0.133/0.161 px**。逐帧相对 stage prior 的修正量级为中位 0.39–0.43 px，这是位移先验与数据驱动对齐之间的真实差距。全部 SR 输入默认使用 contour\_refined 位移。

### B.2.2 EP04 质量门控

为在对齐结果中区分可靠与不可靠的局部区域，EP04 在参考帧上提取了外轮廓 84 段和内轮廓 390 段，以 13 条完整 X-scanline（208 帧）逐线评估定位精度。门控阈值包括 $\mathrm{SNR} \ge 8$、$\Delta T \ge 0.5\;°\mathrm{C}$、NCC peak $\ge 0.85$、相位覆盖 $\ge 0.15$ px、拟合 $\sigma \in [0.8, 1.3]$ px、split-half $\le 0.04$（A 级）或 $\le 0.06$（B 级），以及 PSF 敏感性 $\le 0.03$。

A 级定位精度的统计结果为：外轮廓 28 段，split-half 中位 0.0277 px、P90 0.0622 px、CRB ratio 中位 1.89×、NCC peak 中位 0.9825；内轮廓 139 段，split-half 中位 0.0273 px、P90 0.0847 px、CRB ratio 中位 2.03×。实测精度约为理论 CRB 下界的 2 倍（见 A.1.3），合理。

通过 gate 的轮廓段按三角色划分：alignment\_input（用于对齐优化）、holdout\_validation（保留验证）和 sr\_target\_not\_truth（重建目标但非对齐真值）。外轮廓通过率 54.8%，内轮廓仅 22.3%。内轮廓的 303 个未过 gate 的段主要失败原因是 sigma\_out\_of\_range（145 段）、fit\_error（71）和 split\_half\_high（45）。这些段恰恰是重建要改善可见性的目标——它们作为 target-not-truth 使用，绝不用作对齐真值。

### B.2.3 相位覆盖

相位 bin 保持性是 2x 重建的关键前提。在四种对齐源下，2x 相位 bin 的占用情况为：无对齐仅占 1/4 bin；stage prior、NCC init、contour refined 均占满 4/4 bin（每格 59–67 帧，entropy ≈ 1.0）。这表明数据驱动的修正没有破坏 stage 设计的相位均匀性。但在 3x/4x 网格上出现了 phase collapse（3x 仅 4/5、4x 仅 4/12 占用），不能作为高倍率可行性证据——与 A.1.3 的 4x 出界结论同向。

## B.3 微扫描运动学与热漂移

### B.3.1 Raster 采集的各向异性

本系统采用步进停拍（step-and-shoot）方式沿 raster 路径采集：行内 X 轴连续步进（16 个坐标点，$0 \to 40$ µm），行间 Y 轴跳一步后开始新一行。由此产生显著的各向异性：行内 X 相邻帧的 acquisition gap 中位仅 1 帧（时间连续），而行间 Y 相邻帧 gap 中位约 16 帧（隔了整行 X 扫描）。Clean set 中 X 相邻对共 232 对，行间 Y 跳变 15 次。

这一各向异性直接影响算法设计。X 邻居时间连续使得行内帧间对比度高度可靠，而 Y 邻居隔整行导致数据约束在 Y 方向较弱。bilinear scatter 的权重因此集中在固定 HR 行上。若使用各向同性正则，会产生水平条纹。TGV 的椭圆对偶投影（Y 方向比 1.5）与 coverage 加权正是为此设计（见 C.4.2）。

### B.3.2 Stage command 并非 ground truth

对 Y-only 坐标相邻帧的分析直接揭示了 stage command 不能作为对齐真值的原因。Y 方向 4 µm / 2 µm 的可见位移比为 0.64（期望 2.0），而 X 方向对照为 2.05。Y 2 µm 的实测投影/prior 比为 1.601（期望约 1），Y 4 µm 为 0.511。这是因为固定 X 的 Y 邻帧隔约 16 帧采集，热场演化污染了 NCC，破坏了位移单调性（X 对照组正常）。

实测位移覆盖也支持这一判断：X 相邻 2 µm 实测位移中位 0.0992 px（命令值 0.2 px），端到端 40 µm 实测 2.0768 px（命令值 4.0 px）。细步进的逐步可见位移系统性低于命令值。

### B.3.3 热场演化时间尺度

session=2 内相邻帧均温跳变中位仅 0.008 °C（远低于噪声底），支持行内相邻帧可比。但整个 session 首尾均温漂移为 −0.60 °C（8.3 倍噪声底），clean 248 帧均温跨度 0.544 °C——慢漂移不可忽略，任何分半设计都必须保持时间混合（A.4.3 中的漂移控制正是该效应的度量）。跨 session 跳变中位 2.91 °C、最大 4.16 °C（40–57 倍噪声底），直接禁止混用。主 session 累计位移轨迹包络 $2.49 \times 7.11$ px，路径总长 61.18 px。
