# 第 1 章 引言（中文打磨稿）

> 本文是论文 **§1（对应英文权威稿 `docs/paper/02_introduction.md`）** 的中文打磨稿。
> 必须保留：三问框架（Q1 信息存在 / Q2 信息送达 / Q3 信息忠实）、贡献 C1–C4、bounded-claim 立场。

长波红外（LWIR）热成像是半导体器件无损检测的标准工具：缺陷、短路与工艺偏差会在芯片内部结构上表现为
亚摄氏度的温度图案。但其光学系统同时受**衍射极限**与**成本**约束。本文研究的系统在 6.4 × 4.8 mm 视场上以
10 µm 探测器间距采样，校准空间分辨率为 20 µm——而我们关心的内部结构（细互连线、zigzag 走线、极板间隙）恰好
位于这一尺度或略低于它。设备方评估过硬件升级路线（约 10 µm 级分辨率的微距镜头）并判定效果不满意；因此真正的
工程问题是：**能否用「计算式」多帧增强，在现有仪器上让芯片内部 contour 变得可见且可靠地更清楚。**

微扫描提供了物理基础：电动台以亚像素步长平移场景（一条 16 位置 raster 线上 2–4 µm command），采集数百帧，
于是这串 burst 携带了单帧不具备的亚像素相位多样性。这正是经典的多帧超分辨（MFSR）设定——但带着一个决定性的复杂之处：
**无论采集时还是任何时刻，都不存在高分辨率热成像真值。** 该模态与该场景没有配对的 HR 传感器；光学显微在辐射学上
不可比，也未与热成像坐标轴配准。于是学习式 SR 的每一项标准配料——配对训练数据、全参考指标、按验证 PSNR 选模型——
在真实数据上**全部不可用**。

这一区在工业与科学成像中很常见，但 SR 文献大多用「移植」来应付：在合成或代理配对数据上训练，部署到目标域，
展示更锐的输出。其危险被非正式地熟知——**幻觉（hallucination）**——却很少被量化。本文**量化它、刻画其机制，
并构建一套 2x contour-level 增强管线，其主张能在量化下存活**。

研究围绕三个问题展开：

**（Q1）数据是否含有超出单帧网格的可恢复信息？** 我们用带正/负/漂移控制组的相位分层 split-half FRC，
为 248 帧 clean 主 session 的相干信息量定界：1/7 cutoff 落在 17.0 µm 周期——**相对 20 µm 分辨率是真实但温和的余量**，
且短于 11–14 µm 的理论奢望。细网格 MAP-TV 去卷积锚把这点余量转化为有限但真实的 contour 增益（zigzag 走线 median FWHM
114 → 100 µm），并立起任何学习方法都必须跨过的经典门槛。

**（Q2）学习模型是否真的「收到」了这份信息？** 一个受控的两臂归因实验表明：在常规的 1x 网格统计输入通道
（对齐后的 mean / median / variance / coverage）下，最细结构的失效模式对 loss 设计与解码器结构**都不变**——
burst 的亚像素相位信息在**输入特征化阶段**就坍塌了，根本没轮到网络使用。把同一信息改成 2x 网格 drizzle 通道注入，
会改变 fine-window 的结构权衡、让相位结构在训练更早期可见，但最终选点仍须经下述保真门控。

**（Q3）模型新增的「细节」是否锚定于观测？** 这里我们报告一个自认为有普遍意义的发现：在合成目标上训练的网络，
在真实数据上沿**观测算子的零空间**（shift ∘ PSF ∘ 探测器积分 ∘ 下采样）漂移。forward-consistency loss 贴在其底部，
真实数据 artifact proxy 却随训练单调劣化——漂移对观测锚定**不可见**，无论窄带还是全带（两种锚定臂都已落地、且都失败）。
因此 loss 侧锚定无法修复它；有效的是通过证据注入、（必要时）residual-over-observation 参数化，以及在 proxy Pareto
前沿上、由视觉 panel 把关的 checkpoint 选点规则，来**为输出设界**。

**贡献。**
- **C1**：一个参数**全部实测**的无 GT burst-SR 问题——电动台-像素旋转角 47.6° ± 0.1°、PSF σ 仲裁到 0.2–0.5 LR px、
  噪声底 0.0724 °C、带 session 门控的 raster 采集结构、248 帧 clean 主 session——外加一个物理匹配的合成训练平台。
- **C2**：一套无 GT 评估协议——受控 FRC、一对观测锚定的耦合 proxy（含「为何二者按构造反相关」的分析）、
  以及一条机械化的 checkpoint 选点规则。
- **C3**：零空间漂移这一发现及其补救。
- **C4**：一个诚实的「经典 vs 学习」裁决——**互补失效模式、无 GT 可认证的单一赢家**：各向异性 coverage-weighted TGV
  把 raster 条纹 artifact 3.87 → 0.695、是可验证 proxy 上最忠于观测的方法，却在最细对角 contour 上印上轻微的
  total-variation 阶梯（"beading"，是 lattice 最高的「忠实」参照）；注入证据的学习重建目视最锐、把中心细梳齿解得最清晰，
  却携带最多不可验证的高频 grain（学习臂 lattice 超过 TGV）并在观测保真上可测量地漂移。我们报告可验证保真 proxy、
  一个结构 grain proxy + 双域 panel，以及一个**显式 task-level** 的 contour 可辨偏好，**并认证不存在单一赢家**——
  视觉偏好不是保真证据，本文不支持任何计量级主张。

我们**刻意为主张设界**：交付物是 2x 输出网格上的 contour-level 可见性——不是 5 µm 分辨率、不是温度计量、不是 4x 复原。
我们认为这种**有界、由证据门控**的表述，正是无 GT 工业 SR 场景可迁移的范式。
