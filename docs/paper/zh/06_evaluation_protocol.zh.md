# 第 5 章 无 Ground Truth 的评估协议（中文打磨稿）

> 本文是论文 **§5（对应英文权威稿 `docs/paper/06_evaluation_protocol.md`）** 的中文打磨稿。
> 本章是全文方法学的核心贡献 C2：在**任何阶段都没有高分辨率热成像真值**的前提下，如何判断「增强」是否可信。

协议分四层，**没有任何单层能独立证明成功**——采纳一个重建需同时通过四层，且每层的失效模式都连同控制组一并诚实披露。
其设计哲学是：在无 GT 区，「看起来更锐」恰恰是失效模式而非目标，因此协议的作用是**对幻觉设防 + 选点（gate & select）**，
而非颁发「分辨率」或「保真」证书。

## 5.1 信息存在性：相位分层 split-half FRC（带控制组）

把 248 帧按亚像素相位分层划分为两半，各自独立重建（drizzle），计算两半之间的 Fourier Ring Correlation（FRC）；
重复 3 个 seed。主 session 读数：

- **1/7 判据 cutoff 位于 17.03 µm 周期（跨 seed std 0.50 µm；half-bit 判据数值相同）。** 即在 20 µm 分辨率之外
  存在**真实但有限**的相干信息，远不及 11–14 µm 的理论奢望。
- band 表（周期 → FRC）：20 µm 0.348、16 µm 0.138、14 µm 0.098、**12 µm 0.593、11 µm 0.877、10 µm 0.935**、
  9 µm 0.816、8 µm 0.545。
- **控制组与诚实 caveat。** 10–12 µm 处的高频回弹若可信会很激动人心，但控制组否定了它：bicubic 正控制组**没有**
  出现预期的更低 cutoff（反而 13.58 µm），shift-shuffle 负控制组在 8–12 µm 仍保持 median FRC 0.504（未如预期坍塌），
  acquisition-order 漂移控制组把 cutoff 劣化到 26.20 µm，且细网格上的平均零覆盖率达 27%。因此我们把该回弹归因于
  **覆盖/lattice 伪影 + 热漂移**，标注为**风险而非分辨率证据**，并**只基于 17 µm cutoff 立论**。

MAP-TV 去卷积后，split-half FRC 在 20/16/14/12/10 µm 读数为 0.976/0.965/0.955/0.947/0.934（裸 drizzle：
0.319/0.088/0.053/0.575/0.893）——去卷积提升的是 split-half **一致性（consistency）**；这是稳定性证据，不是光学真值。

## 5.2 观测锚定的 proxy 对——及其「构造性反相关」

在真实数据上，我们针对 raw-bicubic 控制追踪两个 proxy：**artifact score**（超额高通能量比）与
**raw-control correlation**（与控制的高通相关）。两者都是**同一高通残差的泛函**：沿「合成先验风格化」方向移动
（边缘比观测支持的更亮/更宽）会**按构造同时**抬高前者、压低后者。由此三条推论：
（i）这对 proxy 是**漂移温度计 + 选点准则**，不是两个可被联合最大化的独立分数；
（ii）**跨输入模式的数值比较无效**（注入证据的输入天然携带更多高频能量，§4 的硬红线）；
（iii）**沿训练步的轨迹**才是信息量所在，端点值不是。

## 5.3 零空间漂移诊断

把任意重建变化对观测算子 A（§3.4）分解为 δx = δx_range + δx_null，则 A·δx_null = 0——**任何观测域 loss 都看不见 δx_null**。
实际诊断每个训练 run 只需两条曲线：forward-consistency loss（是否贴底？）与真实数据 proxy 轨迹（是否持续漂移？）。
**贴底 + 持续漂移 = 漂移落在零空间**，此时更强的观测锚定**可证明无用**；补救只能来自先验（训练分布）、输入（证据注入）
或选点。§6 的实测实例：forward loss 自 10K 起贴底 0.004–0.009，同期 artifact 从 0.37 爬到 0.65。

## 5.4 结构级指标与视觉门控

- **Zigzag 走线 profile 指标**（客户关心的中心走线）：在固定横截面上测每条 profile 的表观 FWHM 与谷深（dip）；
  报告 median FWHM/dip 及 per-profile 分布；per-profile 结果混杂时如实报告为「混杂」，不取巧。
- **双域视觉 panel**：高通结构图（边缘证据；红/蓝 = 相对局部背景的有符号响应，白 ≈ 无变化）**与**普通温度图
  （inferno，1–99 百分位）并列——后者专门抓「只有边缘变亮」这类被高通图美化掉的失效。
- **对齐门控一致性**（EP04 角色）：重建不得劣化被门控锚点上的 hold-out 轮廓一致性。

## 5.5 采纳规则（Adoption rule）

一个学习臂被采纳，当且仅当在其**选定 checkpoint**（§4 选点规则）上同时满足：
（a）FRC band 一致性 ≥ MAP-TV 锚；（b）zigzag FWHM/dip 不差于锚；（c）proxy 轨迹无 post-selection 漂移悬崖；
（d）双域视觉 panel 均通过。否则**经典锚仍是交付物**。正是这条保守规则，让诚实的负结果（PixelShuffle 头、4x 网络、
loss 侧锚定）与阳性结果得以并列报告——拒绝一个臂和采纳一个臂用的是同一把尺子。
