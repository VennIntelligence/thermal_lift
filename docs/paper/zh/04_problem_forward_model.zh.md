# 第 3 章 问题设定与标定化观测模型（中文打磨稿）

> 本文是论文 **§3（对应英文权威稿 `docs/paper/04_problem_forward_model.md`）** 的中文打磨稿，
> 供人机共写阶段审阅/进修；迁 LaTeX 时统一译英并与英文稿合并为单一事实来源。
> 全章数字均为系统实测，括号内给出出处（Episode / 报告）。**两条铁律**：① 每个数字可指到仓库内权威文件；
> ② pitch（采样间距）、spatial resolution（空间分辨率）、output grid（重建网格）三者贯穿全章严格区分。

红外热成像在工业芯片检测中的根本困难，不是「不够锐」，而是**无法验证「锐」是否真实**。本章先把系统、数据与
标定链按可复现的口径钉死，并在 §3.4 写出一个**参数全部实测**的观测算子——它的带限衰减、混叠折叠，尤其是它的
**零空间**，将统一支配后续的方法（§4）、评估协议（§5）与漂移分析（§6）。

## 3.1 仪器与数据

- LWIR 长波红外相机，波段 8–14 µm；探测器 640 × 480；**探测器采样间距（detector pitch）10 µm/pixel**
  （BMP 毫米标尺实测 10.000，TXT/BMP 轮廓交叉校验 9.980，外掩膜 IoU 0.9938；EP03）。FOV = 6.4 × 4.8 mm。
- **校准得到的空间分辨率为 20 µm**——它与 10 µm 的采样间距是**两个不同的物理量**：前者由光学系统（衍射 + PSF）
  决定，后者只是探测器抽样密度。客户关心的芯片内部结构（细互连线、zigzag 走线、极板间隙）恰好位于 20 µm 分辨率
  尺度上或略低于它。论文图 F1 用同一物理距离轴显式画出 pitch / resolution / 2x SR grid 三者的区别。
- 原始输出是**温度矩阵**（°C，TXT），不是渲染后的伪彩视频。渲染后的 AVI/BMP 导出件作为数值 SR 输入被排除
  （8-bit 量化、约 67% 重复帧；EP01），仅用于位移**方向**的独立旁证（见 §3.3）。
- 噪声底（noise floor）**0.0724 °C**（平滑区相邻坐标 MAE；EP01/EP03）。代表性对比度：内轮廓 median |ΔT|
  1.938 °C（SNR 26.8），外轮廓 2.490 °C（SNR 34.4）（EP03）——即结构信号本身远高于噪声，瓶颈在光学带限而非探测器噪声。

## 3.2 微扫描采集与 session 结构

- **步进停拍（step-and-shoot）raster**：行内 X 轴连续步进（每行 16 个坐标，X、Y ∈
  {0, 2, …, 18, 20, 24, 28, 32, 36, 40} µm，非均匀），行间 Y 轴跳一步后再开新行。
  **行内相邻帧时间连续**（采集间隔 = 1），**行间相邻帧相隔约 16 帧**——这一各向异性同时影响对齐验证与重建
  （§4 的各向异性 TGV 正是针对它）。
- 共 263 帧，按**采集顺序**分为 3 个温度段；主温度段含 255 帧；剔除重复采集帧（R ≠ 0）后得到全程使用的
  **248 帧 clean set**。跨 session 温度跳变中位达 **2.91 °C、最大 4.16 °C（约 40× / 57× 噪声底）**
  （EP01 audit 权威口径；此数取代早期稿中的 3.55 °C/49× 旧值），因此**绝不跨 session 混用帧**。
- 采集顺序由文件 mtime 确立，**不是**按文件名字母序——文件名坐标是标识符而非时序（EP01；按文件名排序会制造 13 个假 session）。

## 3.3 标定链（实测，含不确定度）

**电动台-像素旋转角。** θ = **47.6° ± 0.1°**，项目第一天即标定（EP02）；连续扫描视频的梯度-NCC 独立估计给出
θ ≈ 47.14°，95% CI [46.36°, 47.92°]，**覆盖**标定值（EP02 Phase 9）。stage command 经 θ 与 10 µm pitch 映射为
像素位移，40 µm command 对应 4.0 px。**command 只能作先验、初始化与正则目标，绝不作对齐真值。**

**点扩散函数（PSF）。** 三条估计路线若朴素套用会超容差分歧（forward-residual 0.226、ESF 拟合 1.129、
联合 hold-out 0.119 LR px；极差 1.01 px；EP09）。我们用仲裁解决（EP15 M3）：多边 ESF 显示外框表观宽度
（中位 1.015 LR px）被**热学/几何边缘宽度**主导，强内部边缘给 0.747、最锐单边 0.546；对 Gaussian-PSF × 10 µm
box-aperture 的 MTF² 做 FRC 形状拟合则偏好 σ = 0.2 LR px 并向 1.0 单调变差。最终采用可信光学区间
**σ ∈ [0.2, 0.5] LR px**，所有依赖 PSF 的计算要么扫该区间、要么显式标注 σ。ESF 与 forward 的分歧本身是一个 finding：
**表观边缘宽度 = PSF ⊗ 热学边缘宽度**。

**MTF/SNR 可行性（必要条件，不是成功证明）。** 在 2x 重建网格的 Nyquist 周期（10 µm）处，Gaussian-PSF 的 MTF 为
σ = 0.2 / 0.35 / 0.5 LR px → 0.454 / 0.089 / 0.007；在 4x 处 ≤ 0.042，且 σ ≥ 0.35 时实际归零（EP03）。
有效 SNR = ΔT · MTF / noise 判据将 **2x 标记为「在实测对比度下条件可行」、4x 标记为「除最乐观 σ 外不可达」**——
这正是交付网格定为 2x、更细网格只作 contour 过采样的第一性原理依据（EP12 的 4x 网络失败与此界互证）。

**对齐与质量门控。** 数据驱动对齐（高通 NCC 初始化 + 轮廓精修；EP05）把 hold-out 轮廓 Chamfer 距离从
0.381 px（无对齐）、0.240 px（stage 先验）降到 **0.134 px**，同时保持全部 4 个 2x 相位 bin。一个覆盖
84 段外轮廓 + 390 段内轮廓 × 13 条扫描线的 localization benchmark（EP04）把锚点分级为
alignment-input / holdout-validation / SR-target-not-truth 三类角色（A 类 split-half 中位 ~0.027 px）；
未过门控的内轮廓区域**作为「目标」保留**——重建应改善其可见性，但它们永不充当真值。

## 3.4 观测模型

设 x 为 2x 网格上的高分辨率温度图像，第 k 帧观测为

\[
y_k = D\,B\,H\,S_{t_k}\,x + n_k,
\]

其中 \(S_{t_k}\) 按（精修后的）亚像素位移平移，\(H\) 是可信区间内的 Gaussian PSF，\(B\) 是 10 µm 探测器
box 积分，\(D\) 下采样到 1x 网格，\(n_k\) 服从实测噪声底。这一族算子——它的实测参数、它的带限衰减、以及关键的
**零空间** \(\mathrm{null}(A)\)（\(A = D B H S\)）——是全文的主线：任何只在观测域施加的约束都对 \(\mathrm{null}(A)\)
中的分量恒盲（§5.3 据此诊断漂移，§4 据此设计补救）。

## 3.5 主张边界（Claim boundary）

交付目标是**在 2x 输出网格上让芯片内部结构的 contour 更清楚、更稳定**（5 µm 采样、10 µm Nyquist 周期）。
明确不主张：① 5 µm 输出采样 ≠ 5 µm 空间分辨率；② 不做任何温度计量级声明；③ 最细的内部线（10 µm pitch 下约
1–2 px）位于分辨率极限，**完全复原不在物理菜单上**——问题只是它们的 contour 是否在诚实门控下比 LR/bicubic 更清晰、更稳定。
