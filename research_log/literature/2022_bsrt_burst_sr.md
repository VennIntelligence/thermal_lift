## 1. 忠实摘要（核对自 PDF）

| 项 | BSRT |
|---|---|
| 任务 | 多帧 **burst** SR：输入一组**有噪、错位的 LR RAW** 帧，输出一张 HR RGB |
| 输入/输出 | 输入 14 帧 4 通道 RGGB RAW；输出 16-bit RGB |
| **Scale** | **4×**（唯一声明的倍率，无 2×/8×） |
| 退化模型 | xᵢ=(Tᵢ∘I_HR)↓ₛ+ηᵢ：场景运动(平移+旋转)+**bicubic 下采样**+噪声 |
| 架构 | **SpyNet 光流 + 金字塔 Flow-Guided 可变形卷积(FG-DCN)对齐 + Swin Transformer 主干**；PixelShuffle 上采样；1×1 conv 融合 |
| 参数量 | **BSRT-Small 4.92M / BSRT-Large 20.71M**（都比旧 SOTA EBSR 26.03M 小，还更强） |
| 损失 | 合成轨：**纯 L1**；真实轨：**aligned-ℓ1**(先用 PWC-Net 把 GT warp 到输出再算 L1)。**无 GAN/感知/对抗损失** |
| 数据 | 合成 46,839 张 RGB 合成 burst；真实 5,405 个 Galaxy S8 burst patch(DSLR 出 GT) |
| 训练 | 先合成预训练→真实微调(冻结大部分权重只调对齐+部分 conv)；8×2080Ti，约 14 天 |
| 哲学 | **保真，非幻觉**：原文"reconstruct the original image as well as possible, **and not to artificially generate a plausible image**" |

**头条结果**(Table 1): BSRT-Large 合成 PSNR 43.62 / 真实 48.57，均 SOTA；BSRT-Small 4.92M 即超过 26M 的 EBSR。

**关键消融/主张**: 高频细节来自**跨帧亚像素信息聚合**（"aggregate **sub-pixel information** from multi-frames … alleviating the ill-posed problem"）；卷积是局部算子→用 **Swin 做长程依赖**；单一 flow/DCN 不足以处理大而复杂的位移→**光流+可变形卷积 coarse-to-fine 对齐**。

**待核实**: Swin 的 group/block 数、窗口大小、head 数（论文正文未给）。

## 2. 为什么手机敢做 4×（纠正一个直觉）

用户直觉：自然/人文画面"结构更丰富、能学到更多"，所以 4× 还有信息。→ **这是次要原因。** 主因是物理：

1. **多帧亚像素采样 = 真·新信息**。14 帧因手抖落在不同亚像素网格，把"被欠采样混叠"的高频解出来(de-alias)。N 帧把可恢复频率推到约 √N 倍/光学 MTF 上限。**4× 是 14 帧亚像素多样性买单的，不是网络编的。**
2. **手机光学"透得过"高频**：基础分辨率上手机多为**传感器/混叠受限**，镜头 MTF 仍传 2–4× 高频，信息**本就存在**，多帧只是解混叠。
3. **对齐好才用得上**：BSRT 的真正杠杆是**对齐**，用 4.92M 打败 26M。
4. **"内容丰富"的真实作用**：帮网络学**稳健聚合/去噪先验**，并让**残留伪影藏进纹理里**——是帮手，不是 4× 信息来源。BSRT 全程**无 GAN**，证明它是保真不是幻觉。

## 3. 输入模式：BSRT vs 我们（**最本质的差异**）

**BSRT：14 帧全进"学习网络"**
```
14 帧 RAW ─►[SpyNet 学习对齐 + 金字塔可变形卷积 + Swin 学习融合/重建]─► HR
            ▲ 每帧像素都进网络，对齐与跨帧融合都是"学"出来的
```

**我们：先聚合成一张图，再喂 prox**
```
~248帧 ─►[固定融合 fuse→aligned_mean/drizzle，5~9通道]─►聚合图(x0+cond)─►[prox UNet]─┐
                                                                                       ├─►HR
~16帧(子采样)+shifts+PSF ──────────────►[物理 DC: x ← x − η·Aᵀ(Ax−y)]─────────────────┘
            ▲ 学习的 prox 只看聚合图；原始帧只经"手写线性物理项"进来，K=4 次
```

- **BSRT 的学习部分**同时干**对齐+融合+重建**，吃 14 帧全部像素。
- **我们的学习部分(prox)**只吃一张**预聚合图**(5ch 融合特征，或+4ch 相位 drizzle)。多帧信息靠**固定物理算子 Aᵀ(Ax−y)** 每步线性注入，**不是学出来的融合**。
- 这版 **V8/K4 是 `no_drizzle`**：连 drizzle 都去了，喂 prox 的多帧信息**历来最少**(5ch + DC)。
- 即 **BSRT 让网络"看见所有帧、自学怎么对齐和拼"；我们让网络"只看一张拼好的图、物理项替它保证跟各帧一致"。**

这么设计是**故意的反幻觉路线**(ACL-024/026)：多帧一致性做成**硬物理约束**而非**学习融合**，网络就没能力凭空编结构——对检测/计量是对的，且可解释(经典 unrolled 优化：prox=先验，DC=数据项)。

**代价**(正好是 BSRT 三个强项，我们主动放弃)：
1. 无**学习对齐**：对齐外包给 EP04 localization，网络**改不了错的对齐**——而对齐是我们的瓶颈。
2. 无**自适应融合**：aligned_mean 是固定平均，不会"逐区域选信哪帧"。
3. prox 从**已被平均糊掉**的图出发，要往回找已损失的高频。
4. DC 虽注入全帧信息，但只是**一步线性梯度 × K=4**，对帧的利用远弱于 BSRT 的深度学习融合(unroll 注释亦承认"一步梯度非完整投影")。

## 4. 对比表

| | BSRT(手机 burst 4×) | 我们(LWIR 微扫描 2×) |
|---|---|---|
| SR 引擎 | **学习式**：学对齐+融合+上采样 | **物理式**：前向算子+多帧 DC；网络只当 prox/去噪 |
| 学习部分输入 | **14 帧全部像素** | **一张聚合图**(5~9 通道) |
| 多帧信息入口 | 学习网络内部 | 固定物理 DC(16 帧子采样，线性，K=4) |
| 对齐 | **学习**(光流+可变形卷积) | **外包**(EP04，固定，网络不可改) |
| 信息来源 | 14 帧亚像素融合 + MTF 余量 | 微扫描亚像素融合，但 **PSF σ≈0.5px + 噪声 0.0724°C** 可能把 4× 频段压到噪声下 |
| 受限于 | 传感器/混叠(信息在) | **衍射+PSF+噪声**(信息可能不在)+对齐 |
| 内容 | 自然纹理丰富→伪影被掩盖 | **分片平滑**(等温+硬边界)→**伪影极刺眼** |
| 哲学 | 保真(无 GAN) | 保真(物理约束 solver，硬 DC，反幻觉)——**方向一致** |
| 参数量 | 4.92M / 20.71M | **≈7.45M**(K4 shared prox) |

## 5. 启示（落到我们能做的）

1. **复杂度花在对齐+融合+前向模型，而非放开 prox**。BSRT 用更少参数赢，靠的是结构(对齐+长程)而非堆大小。我们最大杠杆是 EP04 对齐/亚像素 shift 估计，不是 prox 容量。
2. **"网络太简单"是误区**：我们 7.45M 夹在 Small(4.92M) 与 Large(20.71M) 之间；BSRT-Small 4.92M 即超 26M EBSR。**问题不是大小，是"聪明用在哪"+ 多帧信息怎么进网络。**
3. **更大网络在信息贫乏+平坦内容下更危险**：4× 频段若在噪声下，强网络要么不还原(继续糊)要么**幻觉**(伪影)。我们的 EP07 网格/絮状正是这种幻觉。保真路线被 4× 冠军(无 GAN)背书。
4. **要长程/全局建模须"尺度无关+抗伪影"**：Swin 长程注意力对自然图好；我们的全局算子(GroupNorm/SE)恰恰造了 extent-shift 伪影(见 EP07 诊断)。教训不是"加 transformer"，是"全局上下文要有原则"。
5. **按信息预算定 scale**：手机 4× 因物理撑得住；我们 2× contour-level 是按 MTF/SNR 预算来的(硬教训 #6)。该量化"几 X 可行"，别抄别的物理体制的倍率。

## 6. 候选实验（"中间路线"：学习管先验/融合，物理 DC 管保真）

> 都在 EP07 框架内，**保留硬 DC** 当幻觉保险；先修好 EP07 的尺度无关/抗伪影再加复杂度。

- **C1 给 prox 更丰富的多帧条件**：no_drizzle→重新加回/增强逐相位通道(相位 drizzle 是这方向的一小步)，让 prox 看到更接近"逐帧/逐相位"的表示。判据：真实图细节↑而 dc_resid 不升、无新伪影。
- **C2 轻量可学习 shift 细化**：在 EP04 之后接一个小模块微调亚像素位移(BSRT 对齐思想的最小移植)，喂给 DC/融合。判据：合成 GT 上 boundary-F1/PSNR↑，真实图 aligned_mean 更锐。
- **C3 信息预算分析(先做，离线无需 GPU)**：给定 PSF σ、噪声底、有效独立帧数，算 2×(及 4×)频段的 MTF×SNR → 给"几 X 可行"一个数字，决定是否值得加 C1/C2。
