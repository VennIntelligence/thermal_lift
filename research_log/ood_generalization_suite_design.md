# OOD 泛化套件设计稿(2026-07-08,owner 方向:真实 2× 已到目视极限,价值转向分布外泛化包络)

> 背景:Stage 2b 判决 H1(域差)、真实域 2× 视觉饱和(owner 目视 + 频带物理:25.45µm 带完整落在 2× Nyquist 内)、
> σ 不可自标定(ACL-059)→ 项目价值主张升级为:**物理约束求解器 + 实测泛化包络 + 分布无关自校准程序**。
> 本套件回答:冻结的学习臂离开训练分布后,沿哪些轴退化、退多快、与经典方法的相对优势何时反转。
> 结果直接喂 v7 池设计(在哪些轴上做随机化)。

## 0. 前置:生成器支持面审计(实现前必做)

逐轴核对 tcforge 生成器现状(`generate_training_pool.py` + tcforge physics/realism/geometry):
motif 族参数化程度、噪声模型可替换性(疑似固定族,微测辐射热计噪声大概率要新写)、PSF 形状/σ 范围、
shift 星座与漂移轨迹、N 范围。缺口列清单报 owner 后再排实现。

## 1. 预注册规则(先立后跑)

1. **OOD 是测量,不是训练场**:全部用**冻结 checkpoint**(v14、v19_etaB)纯推理;禁止依据 OOD 结果回头调任何超参后重测同一轴(那是把 OOD 变 ID);v7 若吸收某轴,新臂在**重新生成的**该轴池上评测。
2. 对照:TGV/MAP-TV oracle + portable 双条件同池同跑(经典方法也会 OOD——portable 条件本身就是"经典的 OOD")。
3. 指标:带限 FRC-vs-GT(25-40µm)+ band RMSE + 低频稳定性三列(ACL-055),全部沿用 stage2b harness 的 metrics 口径;网格门照过。
4. 每轴输出**退化曲线**:x = 轴强度(离训练分布的距离),y = 各臂指标;判读点 = 神经-经典差值的符号反转位置(若有)。
5. 每池 12-24 景、seed 与训练/bench 池不相交;景数与强度档位数在生成前定死,no silent caps。

## 2. 轴与池(按优先级;每轴 2-4 个强度档)

| # | 轴 | 训练分布(v6) | OOD 档位草案 | 动机 |
|---|---|---|---|---|
| A1 | 场景内容 | CPU-motif 几何 + 15% real-like | 新 motif 族:有机斑块 / 文字-序列号 / 同心环 / Voronoi 胞元(各一小池) | 真实域差的头号嫌疑;先验对内容最敏感 |
| A2 | 噪声统计 | 现行噪声模型 | 行/列条纹(微测辐射热计)、1/f、热像素椒盐、噪声幅值 ×2/×4 | 真实探测器噪声与合成模型的差 |
| A3 | 算子误差(σ/shift) | DC 精确 | DC 喂偏:σ_DC ∈ {0.1,0.25,0.4} × 渲染 σ 固定;shift 加偏 {0.05,0.1,0.2}px | **σ 鲁棒带(ACL-059)**;η 反转的机理验证;不需要新池——现有 bench48 + 推理期扰动即可,最便宜先跑 |
| A4 | PSF | 高斯/椭圆/airy,σ∈[0.15,0.55] | σ∈[0.6,0.9] 外推;airy 占比 100%;强椭圆比 | 算子外推 |
| A5 | 帧预算/星座 | N 24-96,现行抖动 | N=12;漂移型轨迹(非随机星座);步距减半 | 采集端práctica价值(更快采集) |

执行顺序:**A3 先行**(零生成成本,今晚可跑)→ A1 → A2 → A4 → A5。

## 3. 实施

- harness 复用 `run_stage2b_synth_benchmark.py`(池目录 + checkpoint 参数化,已支持);A3 需给 recon-neural/recon-classical 加"DC 参数扰动"旋钮(小改,默认关,字节级旧行为)。
- 每轴一个 pool config(v6 逐字拷贝 + 该轴键变更,沿用 bench48 的"仅 N 键差异"测试模式);生成 CPU ~分钟-半小时/池。
- 汇总产物:每轴退化曲线 CSV+png,终表 = 泛化包络一页图(轴 × 臂 × 强度热图)——进 TensorBoard visboard run,owner 浏览器直接看。
- 判读与 v7 馈送:神经掉崖的轴 → v7 randomize;神经平缓且优于经典的轴 → 论文卖点;经典也掉的轴 → 采集/物理问题,不归网络。
