# 合成数据真实度调优心得 (Synthetic Data Realism Tuning)

> 2026-06-26。本轮把合成数据从「完美矩形 + 均匀温度 + 叠加式假噪声」调到「视觉上接近真实红外数据」的全过程与心得。
> **方法学是核心**:用 `data/data_raw/infrared_avi/*.txt` 真实帧做**并排对比 + 定量分析**驱动,不靠拍脑袋。
> 未来整理成独立 notebook(暂不做)。预览脚本留在会话 scratchpad;正式集成见同期 commit 的 tcforge realism 模块。

## 动机
真实芯片有**不规则缺陷**(裂纹/断角/孔/边缘断片,尺度 > pitch → 可恢复)、温度场**多层次**;旧生成器只有完美矩形 + 2 级温度 + 一层叠加模糊+噪声。目标:**通用**(不钉死本地标定值,全用宽随机范围),但真实度对味。

## 关键迭代与心得(每条都是踩过的坑)

### 1. 缺陷 (defects)
- 新增不规则原语:`irregular_blob`(径向谐波闭合形 `r(θ)=R(1+Σ aₖsin(kθ+φₖ))`,作孔/断角/边缘断片)、`jagged_crack`(随机游走锯齿中线 + 偶发分叉,膨胀成细线)。
- 全部 **> pitch**(可恢复,不违反 ACL-023 band 诚实)。**每场严重度随机**(稀疏↔密集),保跨场景多样。

### 2. 温度模型(踩坑最多)
- ❌ 按形态给功率(厚块热/细线冷)+ screened-Poisson 大扩散 → 结构糊成软斑,**可超分的结构被抹平**。
- ❌ 关键纠正(用户领域知识):**同一块芯片温度应该差不多**(金属导热好 → 连通结构近似等温);按线宽分温度是错的。
- ✅ 定稿:**每连通件近似等温**(件内一档、件间仅微差 `0.82–1.0×ΔT`)+ 轻微边缘软化(σ≈1.4 HR-px)。"多级"只体现为**件间微差**,不是粗细差。
- 记:变系数热传导 `∇·(k(r)∇T)+q−λT=0`(金属高 k、空洞≈0)物理上更对、能模拟"热沿金属走/被裂纹阻断",但**视觉收益不抵成本,且与"等温"诉求冲突**,本轮不采用(留作未来选项)。

### 3. 噪声(真实数据定量分析驱动 —— 本轮最有价值的部分)
- **方法**:同位置三次重复 `0_0_{0,1,2}.txt`。`R0−R1` = 时间随机噪声(场景+FPN 抵消);`mean(R0,R1,R2)` = 固定结构。再做径向 FFT 功率谱、行/列均值、背景角 patch。
- **实测真相**:
  - 时间随机噪声 ≈ **0.12°C/帧**(R0−R1 std 0.172 /√2),近高斯;
  - 所谓"大团" = **单个光滑 vignette 渐变**(居中、低阶),**不是随机中团块**;
  - 用户感觉的"规律" = **竖向列条纹 FPN**(背景角 patch 肉眼可见、FFT 横亮线证实),幅度 ~0.07–0.09°C;
  - 背景角纯残差 std ≈ 0.087°C。
- ❌ 我踩过的错:① 高斯滤白噪 → 随机中团块;② `detector_realistic` 的强条纹太刻意;③ `spatial_correlated` 中团块。
- ✅ 定稿噪声 = **光滑 vignette(~0.13) + 平滑低幅竖列条纹(~0.028,列相关 σ 2.5–5)+ 细高斯颗粒(~0.10)**,单位 °C。
- **坑(刀割边缘)**:列条纹**又强又尖 + 在 PSF 之后叠加** → 强暗列穿过结构 = 边缘像"被刀割一块"。修法:**调小幅度 + 加宽列相关 + 去掉放大列 envelope**。
- **burst 一致性**:FPN(vignette + 列条纹)在一段 burst 内**固定不变**(不逐帧重采,故多帧平均不会消除它);只有**细颗粒逐帧独立**。

### 4. 显示 / 方法学心得
- `inscribe_disc` 的圆盘是「360° 旋转防裁角」的训练边界,训练只裁**内部矩形 patch**、永远看不到圆 → **预览要裁矩形内部**,别显示成圆形标靶。
- LR 是 **1×(480×640)**,别和 2× HR(960×1280)混显;matplotlib 双线性会把 1px 列条纹**抹成假细线** → 诊断一律 `interpolation="nearest"`。
- 真实 ΔT 很小(hard 0.5–2°C、stress 0.3–0.8),别用 5°C 放大对比度造成"假干净高反差"。

## 最终合成模型(定稿)
- **几何**:现有 `build_scene_mask_with_metadata` + `apply_defects`(随机严重度)。布局多样(居中/散布都行),**不强求紧凑居中**。
- **温度**:isothermal per-component,ΔT 按难度,`T_bg∈[19,23]`,边缘 σ≈1.4。
- **前向**:PSF σ∈[0.15,0.55](椭圆/airy 概率保留)、`physical_block_average` 2×。
- **噪声(burst 级)**:固定 vignette + 宽列条纹 加到**整段 burst**,细颗粒**逐帧**。全部宽随机、不钉本地标定。

## 待办 / 开放项
- **结构精细度**:真实是「一个 die 上细密规则栅格/阵列」,合成偏「粗大随机块」。通用性允许保留多样,但**可加一类"细栅格/阵列"母题**(本轮未做)。
- **PSF / 边缘软硬**:真实边缘更柔,可再调(本轮够用)。
- 整理成 notebook(未来)。
- 范围校准:`result/` 标定 + 本地原数据可用于**定噪声/PSF 范围的上下界**(只定范围、不钉单点),需要时再做。

## 对照锚点(真实数据)
`data/data_raw/infrared_avi/`:480×640 tab 分隔 °C 矩阵,命名 `X_Y_R`(载物台位置 µm + 重复号)。注意载物台移动是 µm 级、相对 9.6×12.8mm 视场近似静止 → **不能靠跨帧中值分离 FPN**,要用同位置重复(R0/R1/R2)分离时间噪声。

## 2026-07-01 — v6 CPU/零件母题池(几何重做,连续密度 + 28µm 诚实地板)

> 目标:把域**收敛到零件/CPU 造型为主**(不泛化成万物),让网络学到可迁移的**真实零件几何先验**,而不是反演生成器公式。以真实锚点 `data/data_raw/infrared_avi/` 并排驱动。配置 `configs/synthetic/pool_2x_v6_cpu.json`(继承 v5 的 PSF/噪声/shift/温度),预览脚本 `scripts/preview_v6_cpu.py`。旧 `build_scene_mask_ic_layout` 路径**字节不变**,新母题经 `geometry.motif_weights` opt-in。

### 1. 母题族(解决旧待办「细栅格/阵列」)
- die/封装轮廓、**细密规则 PGA/BGA/via 焊盘阵列**(即上文待办里那类母题,本轮补上)、走线/引脚总线、散热鳍片,+ 6% generic 少数多样性。
- **形状/边界多样化**(不只矩形):圆角矩形、八/六边形、圆盘、椭圆、`irregular_blob` 不规则边界。新增图元 `make_rounded_rect` / `make_regular_polygon`(带顶点抖动)。

### 2. 填充热 die + 丰富内部(不是空心框)
- die/封装是**填充等温热块**,内部叠 legacy 词汇:实心子块 + 空心 `make_frame` 环 + **细互锁走线沟槽** + 十字 + 焊盘栅格,~40–50% 镜像对称。按连通件等温(die 体+走线一件,子块/pad/frame 各自一件、件间微差)。踩坑:早期把内部做成大黑空腔像"挖洞",已调小/降频,改以细走线+空心框为主。

### 3. 难度分档 → 连续密度(核心)
- **删掉 easy/medium/hard/stress 对几何的控制**。每场抽一个连续 `density∈[0,1]`,只控制内部结构的**数量/密度/对称精巧度**(密度高=结构更多,不是更细);芯片**尺寸恒定大**(单芯片族占画面固定较大比例),不再有"小而稀"的 easy 观感。ΔT 也从难度阶跃改为**连续抽**(`physics_ranges.delta_T_c_continuous`)。`density` 存进 scene metadata。

### 4. 28µm 诚实地板(ACL-023 band 诚实落地)
- pitch=20µm、临界采样、2× 可恢复带 ~20–40µm。**所有结构宽度(线/沟槽/间隙/pad/鳍片)一律 ≥ det·1.4 = 28µm**,pad 栅格 pitch ≥ det·1.6 = 32µm → 任何场景都无亚像素结构(旧 v6 的 12–18µm 细线是幻觉诱饵,已消除)。
- 审计:1500 场 × 6 族 × density[0,1] **0 违规**(最细 28.00µm);分带 `verify_pool_sharpness.py`(可恢复 20–40µm 带 vs 亚像素 <20µm 紧阈值)**PASS**,亚像素能量中位降到 ~0.0004。
- 验证:LR 裁剪里最细结构呈**可恢复的多像素**(fig4/fig2),不是亚像素雪花——band 诚实在图上可见。

### 待办 / 开放项(v6 遗留)
- 低密度 `multi_die`/`trace_bus` 场景偏稀疏(多件族固有形态,属合理多样性,非 bug)。
- die 内部走线偏规则平行,不是真实那种全互锁迷宫;合成先验够用,不必字面复刻。
- 全量池:`ncap=220` 使最密栅格较重,若需要可下调(会略缩低密度裸栅格 footprint)。
