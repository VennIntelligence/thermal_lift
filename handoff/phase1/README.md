# Phase 1 Handoff Index

This folder is a handoff package for planning EP07 and EP08 after the EP06
classic 2x contour-level SR POC.

The user goal for this handoff is:

1. Preserve the current project state, results, constraints, and hard lessons.
2. Summarize what EP01-EP06 have actually proven and what they have not proven.
3. Prepare a research-agent prompt for broad literature, GitHub, and dataset search.
4. Make the next discussion about EP07/EP08 start from evidence instead of memory.

## Documents

| File | Purpose |
|---|---|
| `01_current_project_state.md` | Current goal, core facts, and EP01-EP06 result summary. |
| `02_dataset_physics_and_constraints.md` | Dataset, physics, alignment, MTF/SNR, and validation constraints. |
| `03_problem_map_and_failure_modes.md` | What is still hard: hallucination, 4x claims, optical mismatch, artifacts. |
| `04_methods_and_ep07_ep08_options.md` | Candidate methods and a pragmatic EP07/EP08 design. |
| `05_synthetic_benchmark_plan.md` | Proposed generated-data benchmark with true HR thermal ground truth. |
| `06_research_agent_prompt.md` | Copy-paste prompt for a research agent. |
| `07_search_leads_and_sources.md` | Initial literature/dataset/tool leads from local and web search. |
