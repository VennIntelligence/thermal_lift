### 实际系统模糊有多个来源

    真实观测 = [芯片热场] * [热扩散 PSF] * [光学 PSF] * [探测器响应] + [噪声]
                             ~0.5-1 px        ~0.2 px       ~像素化

   模糊来源                                  │ 性质                                          │ 大小估计
  ───────────────────────────────────────────┼───────────────────────────────────────────────┼───────────────────────────────────────────────────
   光学 PSF                                  │ 衍射+像差，近 Gaussian                        │ σ ≈ 0.1–0.2 px (Route A/C)
   热扩散                                    │ 物理热传导，模糊边缘                          │ 取决于材料/激励，可能 ~1 px
   探测器响应                                │ 像素内积分 + 串扰                             │ rect function 卷积
   边缘本身的物理宽度                        │ 芯片结构不是理想阶跃                          │ 取决于层/工艺

  Route B（ESF）测量的是所有这些的叠加（σ ≈ 1.15），Route A/C 测的是光学 PSF 那一小部分（σ ≈ 0.12–0.18）。它们量化的不是同一个东西。

  ### 对你的目标意味着什么

  你的目标是：

  │ 通过 255 帧微动，在 2×–4× 下把中心模糊的细小结构轮廓分开，让零件温度差异可辨别

  关键点是：你要分辨的「模糊」不只来自光学 PSF。即使我们把光学 PSF 完美去除（它只有 σ ≈ 0.18
  px，影响很小），中心区域的细小结构仍然会被热扩散模糊。这是物理上不可逆的——热量在材料中扩散造成的边缘宽化，不是光学系统的问题。

  ## 实际可行的方案

  既然光学 PSF 很小（forward model 对它不敏感），真正需要处理的是系统等效 PSF。我建议：

  ### 方案 1：放弃精确 PSF 标定，让正则化决定锐度

  • MAP-TV 的 λ_TV 本质上在「forward model 一致性」和「锐利度」之间取平衡
  • 小 λ_TV → 更锐利但可能有伪影；大 λ_TV → 更平滑但更稳定
  • 直接做 λ_TV 扫描 + hold-out 验证，不需要知道精确 PSF
  • 用 TGV 替代 TV 可以在保持锐利边缘的同时允许平滑温度渐变

  ### 方案 2：用 Drizzle 绕过 PSF 问题

  • Drizzle 不需要 PSF 模型——它只做位移 + 覆盖加权
  • 对于 2× 效果可能接近 SAA，但有明确的覆盖/权重/不确定性图
  • 可以先用 Drizzle 2× 看效果，再考虑是否在 Drizzle 结果上做后处理锐化

  ### 方案 3：如果要做 4×，需要「系统等效 PSF」

  • 不用三条路线分别估计，而是联合估计 σ_effective 和 HR
  • 但 Route C 已经做了这件事，结果是 σ_effective 贴下界
  • 说明在 highpass 域里，TV 正则化和 PSF 是混合耦合的——很难独立标定
  • 4× 的物理可行性在 EP03 已经被判为高风险（MTF@4×Nyquist ≈ 0.000003）
